### D-014 (adenda, fase 3) — Páginas heredadas en el universo noche
Las ~130 páginas heredadas (todas con fondo claro según `scripts/audit-rutas.mjs`) reciben un marco noche global (`body:not(:has(.nx-page))`): fondo azul noche y `main` como hoja crema redondeada. No se tocan colores internos (cero riesgo de contraste). Después se migra página a página a `.nx-*` empezando por home, cuenta, legal, housing y mundo. `/universo-preview/*` queda fuera de catálogo y sitemap a propósito.
